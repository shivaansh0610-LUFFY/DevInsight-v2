## 🧠 What Is DevInsight v2?

DevInsight v2 is not a portfolio viewer. It is an **engineering forensics platform** — purpose-built to answer one question:

> **Who are the real builders?**

Drop any GitHub username. The Intelligence Matrix processes their entire digital soul across **6 specialized analytical engines** and returns a verdict — raw, honest, AI-verified.

Built by **The Zero Bugs Club** for engineers who build, not performers who curate.

## 🚀 Getting Started

### Prerequisites
- Node.js **18+**
- A GitHub Personal Access Token
- An OpenRouter API Key (for Gemini 2.5 Flash)

### 1. Clone & Install

```bash
git clone https://github.com/shivaansh0610-LUFFY/DevInsight-v2.git
cd DevInsight-v2
npm install
```

### 2. Configure Environment

Create a `.env.local` file in the root:

```env
OPENROUTER_API_KEY=your_openrouter_key_here
GITHUB_TOKEN=your_github_personal_access_token_here
```

> [!IMPORTANT]
> `GITHUB_TOKEN` is **required** for the real-time GraphQL heatmap and repository stats.
> Generate one at [github.com/settings/tokens](https://github.com/settings/tokens) with `read:user` and `repo` scopes.

> [!TIP]
> Get your OpenRouter key at [openrouter.ai/keys](https://openrouter.ai/keys) — free tier is sufficient for testing.

### 3. Boot the Engine

```bash
npm run dev
```

Navigate to **`http://localhost:3000`** and enter the matrix. 🟢
